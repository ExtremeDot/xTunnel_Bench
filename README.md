## اسکریپت مدیریت تونل‌های FRP با پشتیبانی از چهار پروتکل

| پروتکل        | توضیح                          | لایه  |
|---------------|--------------------------------|-------|
| **TCP**       | پایدار و پیش‌فرض               | TCP   |
| **KCP**       | مناسب شبکه‌های پرتأخیر و پرلگ  | UDP   |
| **QUIC**      | مدرن، مالتی‌پلکسینگ قوی         | UDP   |
| **WebSocket** | مناسب عبور از فایروال و CDN    | TCP   |

---

### ویژگی‌ها

- مدیریت همزمان چند تونل (تا ۱۰ تونل برای هر پروتکل)
- تشخیص خودکار لوکیشن سرور (ایران / خارج)
- نصب خودکار FRP نسخه ۰.۷۱.۰
- ساخت سرویس systemd با پیشوند جداگانه برای هر پروتکل (بدون تداخل)
- تست سلامت اتصال و تست سرعت با iperf3
- بهینه‌سازی سیستم (BBR + بافرهای TCP/UDP)
- مدیریت کامل (ریستارت، استاپ، لاگ، حذف، کرون‌جاب)
- تأییدیه قبل از انجام عملیات حساس

### راهنمای راه‌اندازی سرور ایران (TCP)

1. نوع پروتکل را انتخاب کنید (اینجا **TCP** را انتخاب می‌کنیم).
2. شماره تونل را وارد کنید (عدد بین ۱ تا ۱۰).  
   **مهم:** ترجیحاً شماره تونل روی سرور ایران و سرور خارج یکسان باشد تا اسکریپت بدون مشکل کار کند.  
   هر شماره‌ای که اینجا وارد می‌کنید، روی سرور خارج هم دقیقاً همان شماره را وارد کنید.
3. نام تونل را وارد کنید (دلخواه و بدون فاصله).  
   مثال: `Turkey`
4. نوع تنظیمات تونل را انتخاب کنید:  
   - گزینه **۱** = استفاده از مقادیر پیش‌فرض (پیشنهادی)  
   - گزینه **۲** = تنظیم دستی  
   مقدار پیش‌فرض `maxPoolCount` برابر **۵۰** است.  
   اگر سرور شما منابع و پهنای باند خوبی دارد، می‌توانید این مقدار را افزایش دهید (حداکثر تا ۲۰۰).  
   **نکته:** روی سرور خارج این مقدار را تقریباً نصف مقدار سرور ایران در نظر بگیرید.
5. در پایان، مشخصات کامل تونل (IP، پورت، توکن و ...) نمایش داده می‌شود.  
   **هیچ دکمه‌ای نزنید** و همین اطلاعات را برای راه‌اندازی سرور خارج آماده نگه دارید.

---

حالا می‌رویم سراغ سرور خارج:

```
3. Setup Client (Kharej)
```

### راهنمای راه‌اندازی سرور خارج (Kharej)

1. نوع پروتکل را دقیقاً همان چیزی که روی سرور ایران انتخاب کردید وارد کنید (مثلاً TCP).
2. شماره تونل را همان شماره‌ای که روی سرور ایران وارد کردید، وارد کنید (مثلاً اگر روی ایران شماره ۱ بود، اینجا هم ۱ وارد کنید).
3. نام تونل را وارد کنید (می‌تواند همان نام قبلی یا نام دلخواه باشد).
4. اطلاعات زیر را دقیقاً از خروجی آخر سرور ایران کپی و وارد کنید:
   - Iran Server IP or Domain
   - FRP Server Bind Port
   - Authentication Token
5. نوع تنظیمات را انتخاب کنید (پیشنهاد: گزینه ۱ - پیش‌فرض).
6. در انتها از شما پورت‌های کانفیگ برای فوروارد شدن را می‌پرسد.  
   پورت‌های مورد نظرتان را با کاما از هم جدا کنید.  
   مثال: اگر پورت کانفیگ شما `49124` است، فقط همین عدد را وارد کنید.  
   اگر چند پورت دارید: `443,80,49124`

پس از اتمام، تونل روی سرور خارج ساخته و راه‌اندازی می‌شود.

### بررسی وضعیت و سرعت تونل

- با **گزینه ۴** می‌توانید از وضعیت اتصال تونل مطلع شوید (Health Check).
- با **گزینه ۶** می‌توانید سرعت، کیفیت و پهنای باند اتصال را بررسی کنید (iperf3 Speedtest).

**نکته مهم برای تست سرعت:**  
ابتدا روی **سرور خارج** گزینه ۱ (Server Mode) را اجرا کنید، سپس روی **سرور ایران** گزینه ۲ (Client Test) را بزنید و تست را انجام دهید.

اگر شماره تونل‌های سرور ایران و خارج یکی نیست، هنگام تست سرعت روی سرور ایران دقت کنید آیا پورت تست سرور خارج با پورتی که نشان داده شده یکی است یا نه.

مثلاً اگر پورت سرور خارج `55111` انتخاب شده ولی در سرور ایران `55110` است، روی سرور ایران عدد پورت `55111` را وارد کنید و Enter بزنید.
